# Yaapple Backend

Первый рабочий каркас API и админ-панели магазина «Яблочный».

## Уже реализовано
- MySQL и автоматическое создание таблиц
- вход администратора
- добавление, редактирование, скрытие и удаление товаров
- категории
- загрузка до 8 фотографий
- админ-панель `/admin`
- публичный API `/api/products`
- проверка `/health`

## Coolify
- Build Pack: Dockerfile
- Port: 3000
- Persistent Storage: `/app/uploads`
